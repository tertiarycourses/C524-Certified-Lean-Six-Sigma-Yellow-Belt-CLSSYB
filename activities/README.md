# Certified Lean Six Sigma Yellow Belt (CLSSYB) — Activities

**C524**  ·  **Version v1 · 23 September 2026**

14 in-class activities (9 core, 5 elective) following the DMAIC roadmap end to end. Every activity runs on one continuous scenario — the **Contoso Service Desk** — so the outputs accumulate into a single improvement package.

## What each activity folder contains

| Artefact | What it is | Who uses it |
|---|---|---|
| `ANN-Facilitator-Guide-*.docx` / `.pdf` | Purpose, materials, set-up, scenario, the numbered run-sheet with facilitator notes, timing, debrief and success criterion | Trainer |
| `ANN-Learner-Worksheet-*.docx` / `.pdf` | The scenario, the steps and a working space to capture the artefact and prompt answers | Learner |
| `ANN-Checklist-*.docx` / `.pdf` | Criteria table to tick before the debrief, plus feedback | Learner group |
| `data/*.csv` | The mock data the activity analyses | Learner |
| `templates/*.csv` | Blank worksheets to complete in a spreadsheet | Learner |
| `solution/*.csv` | Worked answers (Activity 7 only) | Trainer — release after the attempt |

## The shared data set

All activities work from one fortnight of Contoso Service Desk activity: **400 tickets**, **96 defective**, **120 defects** across **6 opportunities per ticket**.

| Measure | Baseline |
|---------|----------|
| Yield | 76% |
| DPU · DPO | 0.30 · 0.0500 |
| DPMO | 50,000 |
| Sigma level | ~3.1 |
| Mean assignment time | 55 min (median 46, sd 31.8) |
| Improvement goal | 30 min |

Every activity works from these same figures, so the outputs stay consistent across the course. Headline values: [scenario-key-figures.csv](scenario-key-figures.csv).
